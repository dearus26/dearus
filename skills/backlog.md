# 나중에 따로 처리해야 할 사항

> 일부러 미뤄 둔 것, 아직 만들지 않은 것, 정해야 하는 것, 코드에서 일부러 단순하게 둔 것을 한곳에 모았어요. 마지막 정리: 2026.11.25 (프론트엔드가 커플 화면 · 답변 신고 · AI 분석 동의 철회 화면 · 429 안내를 만들고 7장 할 일의 상태를 고쳤어요. 앞서 같은 날: 사용 상한 · AI 연결 데우기 · 배포 서버 대화 시간을 반영하고 7장 맨 위의 프론트엔드 할 일을 다시 정리했어요. 그 앞은 2026.11.18 일기 암호화 · 민감정보 동의 · 생년월일 · 답변 신고를 서버에 만들고 7장 맨 위에 프론트엔드 할 일을 모았어요. 그 앞은 2026.11.14 서버의 이미지 올리기 코드 · 명세 정리 반영. 그 앞은 2026.11.11 메신저 업로드를 txt만 받기로 한 결정 반영: 이미지 전용 항목은 지우고, 서버에 남은 이미지 코드 정리는 2장 "메신저 이미지 · txt 방식 반영" 항목에 모았어요. 같은 날 앞서 한 정리: 개인정보처리방침 결정과 그에 따른 할 일 반영. 그 앞은 2026.11.9 txt 원문 저장 · V7 · 페르소나에 원문 더하기를 반영하고 진짜 Claude로 서버 흐름을 끝까지 시험한 결과 반영. 이어서 서버의 이미지 올리기 API · 이미지 읽기, 일기 · 대화 · 리포트의 가림 제거, 1년 만료 삭제 작업 반영. 그 앞은 2026.11.8 메신저 업로드를 이미지 · txt 방식으로 바꾸고 글자 가림을 없앤 결정과, 원문 저장 · 이미지 API · 철회 규칙 · 스토리보드 수정 등 남은 결정 반영. 그 앞은 2026.11.4 소셜 로그인 서버 구현 · 앱 호출 확인 직후).
> 처리하면 상태를 ✅로 바꾸고 날짜를 적어요. 새로 미루는 일이 생기면 여기에 먼저 적어요.

## 7. 프론트엔드와 맞출 것

### 프론트엔드가 할 일 (2026.11.25 기준, main을 pull한 뒤 이 목록부터 봐요)

서버는 아래 기능을 모두 만들어 `main`과 배포 서버(Render)에 올려 뒀어요. 요청 · 응답은 `server/openapi.yaml`이 기준이에요.

**시작하기 전에**

- `git pull` 뒤 `app/`에서 `npm install`과 **`npm run gen:api`** 를 해요. 2026.11.25에 명세에 사용 상한(429) 응답이 더해졌어요.
- 시험은 지금 있는 **개발 빌드 APK**로 해요. 아래 할 일은 모두 화면 · 로직(JS · TS)이라 **APK를 다시 빌드하지 않아도 돼요.** `npx expo start --dev-client -c`로 열면 고친 코드가 바로 폰에 반영돼요. 네이티브 패키지를 더하거나 `app.json` · `app.config.js`의 네이티브 설정을 바꿀 때만 새 빌드가 필요해요. 지금 EAS 프로젝트는 백엔드 담당의 Expo 계정에 있어서, 새 빌드가 필요하면 백엔드 담당에게 부탁해요.
- APK 링크와 `app/.env` 값(`EXPO_PUBLIC_API_MODE=live`, 배포 서버 주소, 카카오 네이티브 앱 키, 구글 웹 클라이언트 ID)은 백엔드 담당에게 받아요. 구글로 로그인할 계정은 Google Cloud의 OAuth 테스트 사용자에 들어 있어야 해요(`skills/social-login.md`).
- 배포 서버에는 가짜 로그인이 꺼져 있어서 카카오 · 구글로만 들어가요. Expo Go로 시험할 때는 mock이나 각자 PC의 서버(`http://PC의 IP:8080`)를 써요.

**할 일 (위에서부터 추천 순서예요)**

1. ✅ **AI 분석 동의 철회 화면을 따로 만들기** (2026.11.25 끝남). 설정의 "AI 분석"에서 `settings/ai-consent`로 들어가요. 동의 중이면 철회하면 무엇이 멈추고 언제 지워지는지 안내하고, 철회한 뒤에는 서버의 `aiDataDeleteAt`을 "○월 ○일에 모두 지워져요"로 보여주고 "다시 동의하기"를 줘요. 스토리보드에는 D 구역으로 더했어요. AI를 부르다 403 `AI_CONSENT_REQUIRED`를 받으면 모든 곳에서 이 화면으로 안내해요(`lib/apiErrors.ts`).
