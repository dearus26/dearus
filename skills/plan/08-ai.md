## 8. AI 활용 계획

> 2026.10.28: AI 모델은 **Claude Haiku 5.5**로 정했어요. 글자(텍스트)만 보내고(이미지 입력은 쓰지 않아요, 2026.11.11), 한국어 말투 품질이 모자라면 대안(Gemini 3.5 Flash-Lite 등)으로 바꿀 수 있게 호출부를 분리해요.

AI 모델은 **Anthropic Claude Haiku 5.5**이고, 아래 기준으로 골랐어요.

### 8.1 선정 기준

| 기준 | 내용 |
|---|---|
| 데이터 정책 | API로 보낸 데이터를 모델 학습에 사용하지 않을 것 (7장 정책과 직결) |
| 한국어 말투 재현 | 카카오톡 말투, 반말 · 존댓말을 자연스럽게 재현할 것 |
| 스트리밍 지원 | 세부 목표 3 "첫 응답 5초 이내" 달성에 필요 |
| 비용 | 입력 · 출력 토큰 단가, 캐시 할인 여부 |
| 보관 기간 · 처리 위치 | 보관 기간을 숫자로 밝히는지, 글자가 한국 밖에서 처리되는지 (국외 이전 안내 필요 여부) |

### 8.2 선정 결과 — Claude Haiku 5.5

| 항목 | 내용 |
|---|---|
| 모델 | Anthropic Claude Haiku 5.5 (`claude-haiku-5-5`) |
| 요금제 | 종량제 API(상업 약관). 기본값으로 모델 학습에 쓰지 않음 |
| 단가 | 입력 $0.10 · 출력 $0.50 (100만 토큰당, 요청 한 번의 프롬프트가 10만 토큰 이하일 때. 넘으면 $0.50 / $2.50). 추론(thinking) 토큰은 출력 단가로 청구 |
| 예상 비용 | 20턴 대화 1세션 약 $0.013, 수업 개발 · 평가 단계 월 $1~5 수준 (추정. 새 토크나이저는 같은 글자를 Haiku 4.5보다 약 30% 더 많은 토큰으로 세므로 실제 요청으로 다시 재요) |
| 입력 형태 | 글자(텍스트)만 보내요. 이미지 입력은 쓰지 않기로 했어요(2026.11.11). 프롬프트 한 번이 10만 토큰을 넘으면 단가가 올라서, 넘치지 않게 나눠 보내요 |
| 호출 설정 | 추론(thinking)이 기본으로 켜져 있고 `max_tokens`에 포함돼요. 대화는 `effort: low`(첫 응답 5초 목표), 주간 요약은 `medium`으로 시작해서 시험으로 정해요. `temperature` 같은 샘플링 값은 못 보내고(400), 마지막에 assistant 메시지를 미리 채우는 방식(prefill)도 못 써요 |
| 주의 | 입력 · 출력은 Anthropic 서버에서 30일 안에 삭제되고(정책 위반으로 걸리면 최대 2년), 처리 위치는 확인하지 못했어요. 안전 장치가 요청을 거절(`refusal`)할 수 있는데 서버 쪽 자동 대체 모델이 없어요. 지금은 거절되면 서버 오류(`AI_REFUSED`)로 알리고, 짧은 대체 답을 쓸지는 베타에서 얼마나 나는지 보고 정해요. 한국어 말투 품질은 8.5에서 확인해요 |

### 8.3 후보 비교 (2026.10.28 기준)

> **결정(2026.10.28): Claude Haiku 5.5.** 보관 기간을 숫자(30일)로 밝혀서 동의 화면에 쓸 수 있고 단가가 낮아서예요. 말투 품질은 8.5에서 확인해요.
>
> 가격과 약관은 각 회사의 공식 문서(표 아래 출처)를 읽고 적었어요. 가입 전에 콘솔에서 다시 확인해요. 이 표는 Claude(Anthropic의 모델)로 정리했고 Anthropic도 후보에 들어 있으니, 숫자는 출처의 공식 문서로 직접 확인해 주세요.

**가격** (USD, 100만 토큰당)

| 회사 | 후보 모델 | 입력 | 출력 | 20턴 1세션 (추정) |
|---|---|---|---|---|
| Google (대안) | `gemini-3.5-flash-lite` | 0.30 | 2.50 | 약 $0.045 |
| Google | `gemini-3.8-flash` | 0.75 (2026.12.31까지, 2027.1.1부터 1.50) | 3.75 (이후 7.50) | 약 $0.10 (이후 $0.20) |
| Anthropic | `claude-haiku-5-5` | 0.10 (요청 한 번의 프롬프트가 10만 토큰 이하일 때) | 0.50 | 약 $0.013 |
| Anthropic | `claude-sonnet-5-5` | 2 | 10 | 약 $0.26 |

추정 가정은 기존 $0.04 추정과 같아요: 세션 하나에 입력 합계 10만 토큰(매 턴 지금까지의 대화를 다시 보내요), 출력 6천 토큰. 추론(thinking) 토큰이 출력에 더해지면 더 나와요. 수업 규모(약 200세션)로 보면 Haiku · luna 약 $3, Solar 약 $7, Flash-Lite 약 $9, Sonnet 약 $52라서 **Sonnet급이 아니면 가격은 결정 요인이 아니에요.** Upstage는 정가이고 가입 프로모션 할인은 뺐어요.

**데이터 약관**

| 회사 | 모델 학습에 사용 | 보관 | 처리 위치 · 기타 |
|---|---|---|---|

| Anthropic API | 기본값으로 안 씀 (피드백 버튼 · 별도 동의 제외) | 입력 · 출력을 30일 안에 삭제해요. 정책 위반으로 걸리면 입력 · 출력 최대 2년, 분류 점수 최대 7년이에요. Fable 5 · 5.1과 Mythos 5 · 5.1은 "지정 모델"이라 최소 30일 보관하고 자동 안전 검사를 받으며 보관 0일(ZDR)이 안 돼요. Haiku · Sonnet · Opus 5.5는 해당 없어요. 지정 모델이 아닌 모델의 보관 0일(ZDR)은 승인제예요 | 처리 위치는 확인 못함 |
| OpenAI API | 기본값으로 안 씀 (동의해야 사용) | 악용 감시 로그 최대 30일이에요. 보관 0일(ZDR)과 수정된 감시는 승인제예요 | 한국 지역(`kr.api.openai.com`)이 있지만 저장만 한국이고 처리는 아니며, 승인과 영업팀 문의가 필요해요 |
| Upstage | 안 씀 (문서에 "이 API에서 데이터를 수집하지 않는다"고 적혀 있어요) | 서비스에 필요하지 않으면 저장하지 않아요 | 처리 위치는 확인 못함 (국내 회사) |
| Naver | 확인 못함 | 확인 못함 | 확인 못함 (국내 회사). 이용약관과 요금 안내를 직접 확인해야 해요 |

**읽는 법**

1. 학습 미사용은 Google 유료 · Anthropic · OpenAI · Upstage 모두 가능해요. 차이는 보관 기간을 숫자로 약속하는지예요. Anthropic과 OpenAI는 30일, Google은 기간을 안 적었고, Upstage는 "저장 안 함"이에요.
2. 미국 회사 3곳은 글자가 한국 밖에서 처리돼요. 개인정보가 해외로 나가는 일이라 약관 · 동의 화면 문구에 반영하고, 개인정보 국외 이전 규정에 걸리는지 확인이 필요해요(법률 검토). 글자를 가리지 않고 보내서 메신저 대화와 일기 본문의 감정 · 관계 이야기가 그대로 AI 회사로 가요.
3. "30일 보관"은 우리 서버가 아니라 AI 회사 서버에 남는 기간이에요. 사용자가 동의를 철회하면 우리 서버는 30일 보관한 뒤 지우고, AI 회사에 이미 보낸 글자는 보낸 뒤 그 회사의 기간(Anthropic은 30일 안, 정책 위반으로 걸리면 더 길게)만큼 남아요. 두 기간이 맞아서 동의 화면에 "철회하면 약 30일 뒤 모두 지워져요"로 한 번에 안내할 수 있어요.
4. 한국어 말투 재현과 "그 시점의 나" 유지 품질은 문서로는 알 수 없어요. 8.5에서 직접 시험해요.
5. 스트리밍과 첫 응답 시간은 이번에 확인하지 않았어요. 8.5 시험에서 같이 재요.

### 8.4 단계별 사용 방식

| 단계 | 사용 방식 | 데이터 |
|---|---|---|
| 개발 · 테스트 | Anthropic API (시험용 데이터만) | 직접 만든 일기, 팀원 본인이 동의한 샘플 대화만 사용 |
| 말투 품질 확인 시험 | Haiku 5.5와 대안 (시험용 데이터만) | 같은 시험용 샘플로 블라인드 비교 (8.5) |
| 메신저 txt 읽기 시험 | 폰 안 txt 읽기 규칙 (AI API 아님) | 안드로이드 · 아이폰 형식의 카카오톡 txt에서 내 이름의 줄만 남는 비율 100%를 확인하는 방식으로 테스트 진행 예정 |
| 「나 같다」 평가 · 발표 시연 | Anthropic API (상업 약관, 학습 미사용) | 실제 참가자 데이터 (동의 화면에 30일 보관 안내 후) |

AI를 쉽게 교체할 수 있도록, 서버에서 AI 호출부를 인터페이스로 분리하고 주소와 키만 설정으로 바꾸는 구조로 설계해요.

메신저 txt에서 내 말을 추리는 일은 AI API가 아니라 폰 안에서 해요. 글자를 가리는 처리는 하지 않아요.

### 8.5 말투 품질 확인 시험

Haiku 5.5로 정했지만 한국어 카카오톡 말투를 얼마나 닮는지는 아직 보지 않았어요. 아래 시험으로 확인하고, 기준에 못 미치면 대안으로 바꿔요.

| 항목 | 내용 |
|---|---|
| 비교 대상 | Claude Haiku 5.5(선정)와 Gemini 3.5 Flash-Lite(대안). 점수가 비슷하면 한 단계 위 모델(Claude Sonnet 5.5)도 넣어 큰 모델이 얼마나 올리는지 봐요 |
| 데이터 | 직접 만든 일기와 카톡 요약 5세트(반말 짧게, 존댓말 길게, ㅋㅋ 많이 등 말투를 다르게). 같은 프롬프트로 세션당 5턴. 실제 참가자 데이터는 쓰지 않아요 |
| 평가 | 모델 이름을 가리고 섞어서 팀원과 동의한 지인이 1~5점: 말투가 닮았는지, 그 시점의 나를 유지하는지(오늘 일을 모르는 척), 따뜻하고 안전한지(힘든 이야기 · 위기 표현에 대한 대응), 첫 응답 시간(초) |
| 통과 기준 | ① Haiku 5.5의 블라인드 평균이 대안보다 0.3점을 넘게 낮지 않을 것 ② 첫 응답 5초 이내 ③ 위기 표현에 안전하게 답하고 거절(`refusal`)되지 않을 것 |
| 못 미칠 때 | 먼저 `effort`와 프롬프트를 손봐요. 그래도 안 되면 대안(Gemini 3.5 Flash-Lite 또는 Solar Pro 4)으로 바꾸고, 동의 화면의 AI 회사 보관 안내도 함께 바꿔요 |
| 일정 | 개발은 Haiku 5.5로 계속해요. 호출부를 인터페이스로 분리해 두어서 바꿔도 주소 · 키 · 모델명만 달라져요 |
