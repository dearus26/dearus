## 1. 개요

### 1.1 서비스 정의

일기와 메신저 · 업무 채팅 데이터를 기반으로 과거의 자신을 AI 페르소나로 재현하여, 특정 시점의 '나'와 직접 대화하고, 커플은 서로 상대의 과거 페르소나와 대화하며 같은 날의 마음을 비교하는 회고형 서비스.

### 1.2 서비스 흐름

```
① 데이터 기록 → ② 분석 · 축적 → ③ 과거의 나 생성 → ④ Time-Slip Chat & 회고
```

| 단계 | 내용 |
|---|---|
| ① 데이터 기록 | 일기 작성(기본). 일기를 쓰기 귀찮을 때는 카카오톡 대화 이미지(스크린샷) 또는 내보내기 txt 업로드(대체). txt는 앱이 폰 안에서 내 말만 추려 사용자가 확인한 글자를 서버로 보내고, 이미지는 서버가 AI로 내 말을 읽어 분석 |
| ② 분석 · 축적 | 일기는 그대로, txt는 폰이 사용자가 고른 내 이름의 말만 추려(상대 말은 폰에서 버림) 서버로 보내고, 이미지는 서버가 AI로 내 말풍선만 읽어 말투 · 어휘 · 성향 · 당시 감정과 상황 분석 |
| ③ 과거의 나 생성 | 바로가기(1개월 / 6개월 / 1년 전)는 그 무렵 전후 2주, 캘린더에서 직접 고른 날은 그날 하루의 일기 · 메신저 요약으로 AI 페르소나 구성 (최대 1년 전까지 선택) |
| ④ Time-Slip Chat & 회고 | 과거의 나와 대화 → 현재와 비교 → 성장 리포트 |

데이터가 부족한 시점은 "기록이 부족해 정확도가 낮을 수 있어요" 안내 후 대화를 진행해요.

### 1.3 핵심 기능

| 기능 | 내용 |
|---|---|
| 📖 일기 기록 & 캘린더 (핵심 콘텐츠) | 하루의 일기와 감정을 기록하고 날짜별로 과거 기록 조회 (기록이 있는 날은 그날의 감정 색 점으로 표시, 날짜를 탭하면 그날의 나와 대화) |
| 💬 메신저 대화 분석 (일기 대체 입력) | 일기를 쓰기 귀찮을 때 카카오톡 대화를 이미지나 내보내기 txt로 올리면 내 말만 읽어서(txt는 폰이 추리고 상대 말을 버려요, 이미지는 AI가 읽어요) 말투 · 어휘 · 대화 성향을 분석 · 축적 |
| ⏳ Time-Slip Chat | 고른 시점(전후 2주 또는 그날 하루)의 데이터로 과거의 나를 재현해 실시간 대화하고, 지난 대화는 "과거의 나" 목록에서 다시 열어요 |
| 📊 회고 & 성장 리포트 | 과거의 고민과 현재를 비교해 변화 · 성장 과정 확인 |

### 1.4 서비스 모드 — 하나의 엔진, 두 가지 사용 방식

| 구분 | 개인 모드 | 커플 모드 |
|---|---|---|
| 페르소나 | 내 기록으로 과거의 나 생성 | 두 사람이 각자 자기 계정에서 일기 · 메신저 txt로 기록을 쌓아 자기 페르소나를 만들고, 그 페르소나를 연인에게 공개 |
| 연결 조건 | 없음 | 초대 코드로 두 계정 연결, 양측 모두 동의해야 시작 |
| 대화 대상 | 최대 1년 전까지 고른 시점의 나 (바로가기: 1개월 · 6개월 · 1년 전, 또는 캘린더에서 고른 날) | 두 사람의 기록이 모두 있는 날의 연인 (상대방의 과거 페르소나와 대화) |
| 대화 이후 | 당시 고민 · 현재 변화 · 한 줄 요약 리포트 | 같은 날 두 사람이 각자 나눈 대화를 나란히 보고 간극을 한 줄로 확인한 뒤, 현실에서 만나 이야기 |

- 커플 모드는 서로 **상대방의 과거 페르소나와 대화**해요(2026.11.7 확정). 함께 볼 날을 고르고, 서연은 그날의 도윤과, 도윤은 그날의 서연과 대화한 뒤, 두 대화의 요약을 나란히 비교해요. 내 기록으로 만든 페르소나가 연인과 대화하고 그 내용이 비교 화면에 나오기 때문에 양측 동의가 필요해요.
- 커플 모드는 개인 모드와 같은 페르소나 엔진을 재사용해요. 페르소나의 주인만 연인으로 바뀌어요. 추가 개발 범위는 계정 연결, 양측 동의 플로우, 함께 볼 날 고르기, 상대 페르소나 대화 세션, 두 시점 비교로 한정돼요.
- 앱 안에 실시간 공유 화면을 두지 않아요. 앱은 대화의 **계기와 소재**를 제공하고, 실제 이야기는 오프라인에서 일어나요.
