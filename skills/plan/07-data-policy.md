## 7. 개인정보 및 데이터 정책

| 항목 | 내용 |
|---|---|
| 수집 동의 | 최초 로그인 때 필수 3개(이용약관, 개인정보 수집 · 이용, 일기 · 대화 내용 AI 분석)에 동의한 경우에만 진행하고, 메신저 업로드는 올릴 때마다 한 번 더 확인("위 내용을 이해했고 대화 분석에 동의해요"). AI 분석 동의는 설정에서 언제든 철회 |
| 소셜 로그인 정보 | 제공자의 사용자 ID와 닉네임(앱이 보낸 이름 또는 제공자 프로필의 이름)만 저장하고 **이메일은 받지도 저장하지도 않아요**. 제공자가 준 토큰은 서버가 확인하는 데만 쓰고 저장하거나 로그에 남기지 않아요 |
| 글자 가림 안 함 | 글자를 가리는 처리(마스킹)는 앱 · 서버 모두 하지 않음(2026.11.8 결정). 사용자는 보내기 전에 내 말을 확인하고, 일기 본문도 그대로 AI API로 보냄. 동의 화면과 약관에 AI 전송과 보관 기간을 분명히 안내 |
| 보관 기간 | 업로드일로부터 1년이 경과한 메신저 원문과 요약은 자동 파기 |
| 파일 처리 | 폰의 txt 파일은 앱이 고치거나 저장하지 않음. 이미지(스크린샷) 올리기는 하지 않음(2026.11.11 결정, 서버의 이미지 올리기 API와 이미지 읽기 코드도 2026.11.14에 지움) |
| 보관 | 메신저는 내 말 원문을 1년 보관하고(만료되면 삭제), 주 단위 요약, 키워드, 말투 특징, 내 대표 문장 일부는 암호화해서 보관. 업로드 기간과 상태를 따로 남김. 일기 원문은 사용자의 열람 · 수정 · 삭제를 위해 저장 |
| 상대방 데이터 | 메신저 속 상대방 메시지는 폰에서 버려 서버로 보내지 않음(내 말만 사용). 커플 모드에서는 내 기록으로 만든 페르소나와 연인이 나눈 대화 · 요약이 연인에게 보이며, 내가 직접 동의한 경우에만 공개 |
| 외부 AI 전송 | 대화에 필요한 데이터만 AI API(Anthropic Claude Haiku 5.5)로 전송하며, 전송 데이터를 모델 학습에 사용하지 않는 서비스만 이용. 보낸 글자는 Anthropic 서버에서 30일 안에 삭제되고(정책 위반으로 걸리면 최대 2년) 한국 밖에서 처리될 수 있어서 동의 화면에 안내. 전송 범위: 메신저는 사용자가 확인한 내 말의 글자만(상대 말은 보내지 않음), 일기는 선택한 구간(바로가기는 전후 2주, 날짜 직접 선택은 그날 하루) 기록만. 시점 분석 때는 보관 중인 내 말 원문 중 같은 구간의 일부(약 1만 자까지)도 다시 보냄(2026.11.9) |
| 이용자 권리 | 언제든 자신의 데이터 열람, 삭제, 동의 철회 가능 |
| 분석 데이터 파기 | 회원 탈퇴, 삭제 요청, 커플 연결 해제 시 관련 페르소나와 분석 데이터 즉시 파기. AI 분석 동의를 철회하면 AI 사용은 즉시 막고, 분석 데이터(메신저 원문 · 요약 · 시점 분석)와 대화 기록은 철회한 날부터 30일 보관한 뒤 파기해요(그 안에 다시 동의하면 이어서 사용). 일기는 지우지 않아요. 회원 탈퇴는 원문도 바로 지워요(2026.11.8 확정) |

**프라이버시 원칙(2026.11.8 변경, 2026.11.11 이미지 제외):** txt는 상대 말을 폰 밖으로 보내지 않아요. 글자를 가리는 처리(마스킹)는 앱 · 서버 모두 하지 않고, 내 말 원문은 1년 보관해요. 2026.10.28에는 폰 안에서 글자를 읽고 가려서 가린 글자만 보내기로 했었어요.

**설계 의도:** 글자 읽기(OCR) · 검수 · 직접 가리기 개발을 없애고, txt를 폰 안에서 추리는 방식으로 단순하게 만들기 위해 바꿨어요(이미지 읽기도 2026.11.11에 뺐어요). 페르소나는 일기와 메신저 주간 요약으로 만들어요.
