## 6. 커플 모드 동의 설계

커플 모드에서는 내 기록으로 만든 과거의 나(페르소나)와 연인이 대화하고 그 요약이 비교 화면에 나오기 때문에, 연인이 몰랐던 생각이나 고민이 드러날 수 있어요. 이 부분은 **커플 모드 시작 시 사전 안내와 동의**로 처리해요.

### 6.1 동의 절차

```
① 초대 코드 연결 → ② 각자 안내 확인 → ③ 양측 개별 동의 → ④ 상대 페르소나와 대화 · 같은 날 비교
```

| 단계 | 내용 |
|---|---|
| ① 초대 코드 연결 | 한 사람이 코드를 발급하고, 상대가 입력하여 연결 요청 |
| ② 각자 안내 확인 | 속마음 노출 가능성을 구체적인 시나리오로 안내 |
| ③ 양측 개별 동의 | 두 사람 모두 동의해야 다음 단계 진행 |
| ④ 상대 페르소나와 대화 · 같은 날 비교 | 함께 볼 날을 고르고, 각자 그날의 연인(상대의 과거 페르소나)과 대화한 뒤 두 대화의 요약을 나란히 볼 수 있음 |

### 6.2 안내 문구 예시

> 상대방이 회원님의 일기와 대화 기록으로 만들어진 '과거의 회원님'과 대화하게 됩니다. 대화나 리포트 중에 상대방이 몰랐던 생각이나 고민이 드러날 수 있어요. 동의는 언제든 철회할 수 있으며, 철회 시 상대방의 접근은 즉시 차단됩니다.
>
> ☐ 위 내용을 이해했으며 커플 모드 데이터 활용에 동의합니다.

위 문구는 앱 화면(스토리보드)과 같고, 상대가 내 과거의 나와 대화하는 확정된 흐름(2026.11.7)과 맞아서 그대로 써요.

### 6.3 규칙

- 한쪽만 동의한 상태에서는 상대의 페르소나 · 기록 · 요약에 접근할 수 없어요.
- 상대 페르소나를 만들 때는 상대의 일기 · 메신저 요약이 AI로 가기 때문에, 커플 양측 동의에 더해 페르소나 주인(연인)의 AI 분석 동의도 유효해야 해요.
- 상대 페르소나는 고른 날까지의 상대 기록만 써요. 그 이후의 일은 모르는 개인 모드 규칙과 같아요.
- 동의 철회 또는 커플 연결 해제 시 상대방의 접근을 즉시 차단하고, 이 커플의 대화와 리포트(기억 요약 · 간극)를 삭제해요. 내 일기와 개인 모드 기록, 내 분석 결과는 그대로 남아요.
