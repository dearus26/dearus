## 2026.11.9 서버 흐름 시험 (진짜 Claude)

상태: 🔧

로컬 서버 + 공용 DB로 앱 순서대로 불러 봤어요. 가짜 로그인 · 동의 · 일기 3편 → txt 업로드(내 말 13개, 3주, 약 6초에 `DONE`, 응답에 `format: TXT`, 예전 `maskedCount` 등은 무시) → 전후 2주 대화 준비(원문 12줄 사용, 구간 밖 말은 빠짐) · 하루 단위(그날 말 3줄만) → 대화 2턴(말투 · 그 무렵 일이 원문대로 나오고, 원문의 전화번호는 말하지 않음) → 이미지를 txt API로 415, `DISCORD` 400 → 회원 탈퇴 204. 서버 오류 로그 0건. 준비 단계는 `COLLECT → ANALYZE`가 보였고(`BUILD`는 너무 빨라 조회에 안 잡힘) `MASK`는 없어요. 시험 계정은 지웠어요. 같은 날 스크린샷 업로드도 진짜 Haiku로 시험했어요: 스크린샷 12장 → 약 20초에 `DONE`(읽기 11초 · 요약 9초, 6주, 10-01~11-07) → 전후 2주 대화 준비 13초(스크린샷 속 일이 그때의 나에 반영됨) → 대화 2턴(첫 글자 1.2~1.3초) → 리포트 5.5초 → 막혀야 하는 요청 6가지(415 · 413 · 400)가 모두 명세대로 → 회원 탈퇴 204. 서버 오류 로그 0건, 로그에 메시지 글자 없음. 남은 시험: 앱 `live` 모드로 폰에서 같은 흐름

## 2026.11.11 커플 흐름 시험 (진짜 Claude)

상태: ✅

로컬 서버 + 공용 DB, 시험 계정 서연 · 도윤. 연결 → 동의 전 403 → 양측 동의 → 함께 볼 날(10월 12일 슬픔 · 불안이 추천됨) → 서연이 그날의 도윤과 3턴 · 도윤이 그날의 서연과 3턴(각자 일기 내용대로 그날의 마음을 말했어요) → 커플 리포트 2개 → 간극 "도윤은 답이 없는 시간이 불안해 자꾸 물어봤지만, 서연에게는 그 다그침이 … 잘못한 사람이 된 것처럼 전해졌어요" → 두 사람 모두 READY · 같은 간극 → 철회하면 두 커플 세션 404 → 탈퇴. 서버 오류 0건. 다듬을 점: 그날의 도윤이 반말 일기인데 존댓말로 답했고 "기록이 적어서 …"처럼 기록을 출처로 말했어요, 그날의 서연이 한 답을 두 문단으로 나눴어요(대화 프롬프트 다듬기와 같이 보기). 간극에 이름이 들어가요(괜찮으면 그대로)
