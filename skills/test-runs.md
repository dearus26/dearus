## 2026.11.9 서버 흐름 시험 (진짜 Claude)

상태: 🔧

로컬 서버 + 공용 DB로 앱 순서대로 불러 봤어요. 가짜 로그인 · 동의 · 일기 3편 → txt 업로드(내 말 13개, 3주, 약 6초에 `DONE`, 응답에 `format: TXT`, 예전 `maskedCount` 등은 무시) → 전후 2주 대화 준비(원문 12줄 사용, 구간 밖 말은 빠짐) · 하루 단위(그날 말 3줄만) → 대화 2턴(말투 · 그 무렵 일이 원문대로 나오고, 원문의 전화번호는 말하지 않음) → 이미지를 txt API로 415, `DISCORD` 400 → 회원 탈퇴 204. 서버 오류 로그 0건. 준비 단계는 `COLLECT → ANALYZE`가 보였고(`BUILD`는 너무 빨라 조회에 안 잡힘) `MASK`는 없어요. 시험 계정은 지웠어요. 같은 날 스크린샷 업로드도 진짜 Haiku로 시험했어요(이미지는 2026.11.11에 빠져서 기록으로만 남겨요): 스크린샷 12장 → 약 20초에 `DONE`(읽기 11초 · 요약 9초, 6주, 10-01~11-07) → 전후 2주 대화 준비 13초(스크린샷 속 일이 그때의 나에 반영됨) → 대화 2턴(첫 글자 1.2~1.3초) → 리포트 5.5초 → 막혀야 하는 요청 6가지(415 · 413 · 400)가 모두 명세대로 → 회원 탈퇴 204. 서버 오류 로그 0건, 로그에 메시지 글자 없음. 남은 시험: 앱 `live` 모드로 폰에서 같은 흐름

## 2026.11.11 커플 흐름 시험 (진짜 Claude)

상태: ✅

로컬 서버 + 공용 DB, 시험 계정 서연 · 도윤. 연결 → 동의 전 403 → 양측 동의 → 함께 볼 날(10월 12일 슬픔 · 불안이 추천됨) → 서연이 그날의 도윤과 3턴 · 도윤이 그날의 서연과 3턴(각자 일기 내용대로 그날의 마음을 말했어요) → 커플 리포트 2개 → 간극 "도윤은 답이 없는 시간이 불안해 자꾸 물어봤지만, 서연에게는 그 다그침이 … 잘못한 사람이 된 것처럼 전해졌어요" → 두 사람 모두 READY · 같은 간극 → 철회하면 두 커플 세션 404 → 탈퇴. 서버 오류 0건. 다듬을 점: 그날의 도윤이 반말 일기인데 존댓말로 답했고 "기록이 적어서 …"처럼 기록을 출처로 말했어요, 그날의 서연이 한 답을 두 문단으로 나눴어요(대화 프롬프트 다듬기와 같이 보기). 간극에 이름이 들어가요(괜찮으면 그대로)

## 2026.11.14 이미지 업로드 정리 뒤 시험 (진짜 Claude)

상태: ✅

서버에서 스크린샷 올리기 코드(`POST /uploads/messenger/images`, `ScreenshotReader` · `MessengerImageJob`, AI 이미지 입력)를 지운 뒤 확인했어요. 단위 시험 315개 통과(DB 시험 8개는 건너뜀), 진짜 Haiku를 부르는 live 시험 9개(대화 스트리밍 · 시점 분석 · 리포트 · 주간 요약) 통과. 로컬 서버 + 공용 DB + 진짜 Haiku로: 가짜 로그인 · 동의 → txt 업로드(내 말 10개, 3주, 약 5초에 `DONE`, `format: TXT`, `photoCount: 0`) → 스크린샷 경로는 405 `METHOD_NOT_ALLOWED`, txt API에 사진은 415 `IMAGES_NOT_ACCEPTED` → 전후 2주 대화 준비 8초 → 대화 1턴(그 무렵 txt에 쓴 "알바 첫날" 일이 그대로 나옴) → 회원 탈퇴 204. 서버 오류 로그 0건. 시험 계정은 지웠어요.

## 2026.11.21 Render 배포 확인

배포된 서버에 시험 계정을 만들어 확인하고 끝난 뒤 탈퇴로 지웠어요. 진짜 Claude는 부르지 않았어요.

- 상태 확인 `UP`. 잠들어 있던 서버의 첫 응답까지 약 109초였어요.
- 가짜 로그인, `/me`, 동의(민감정보 없이 보내면 400, 넣으면 200), 일기 쓰기 · 읽기, 탈퇴가 모두 됐어요.
- 암호화 키: 로컬 서버가 잠근 일기를 배포 서버가 읽고, 배포 서버가 잠근 일기를 로컬 서버가 읽었어요. 두 곳의 `ENCRYPTION_KEY`가 같아요.
- 응답 시간(PC에서, 15번의 중앙값): DB를 안 쓰는 요청 150ms, `/me` 308ms, `/diaries` 309ms. 같은 DB에 붙은 로컬 서버의 `/me`는 48ms였어요.
- 아직 안 본 것: 진짜 Claude의 대화 첫 글자 시간과 Render를 거친 SSE 스트리밍.

## 2026.11.21 소셜 로그인 시험 (Android 개발 빌드)

EAS 개발 빌드(APK)를 안드로이드 폰에 설치하고 배포 서버에 붙여 시험했어요.

- 첫 EAS 빌드 성공(약 20분). Windows 로컬 빌드를 막던 경로 길이 문제는 EAS에서는 나지 않았어요.
- 진짜 계정으로 로그인한 뒤 서비스 이용 동의 화면까지 들어갔어요.
- 배포 서버는 가짜 토큰을 401로 거절하고, 애플은 501, 가짜 로그인은 404예요.
- 그 뒤 앱 동의 화면을 고쳤어요. 아래 "동의 화면 시험"을 봐요.

## 2026.11.21 동의 화면 시험

- 웹 미리보기(mock, 폰 크기): 잘못된 생년월일은 버튼이 꺼지고, 만 14세 미만은 안내가 뜨고 동의 화면에 남고, 올바른 값이면 홈으로 들어가요. 민감정보 안내 문서도 열려요.
- 실제 서버(로컬, 공용 DB): 예전 요청 400, 생년월일 없음 400, 14세 미만 403(아무것도 저장 안 됨), 첫 동의 200, 알림 변경 · 철회 · 다시 동의 200, 생년월일은 다시 보내도 안 바뀌어요. 시험 계정은 지웠어요.
- 아직 안 본 것: 폰의 개발 빌드에서 진짜 계정으로 동의를 끝내고 홈까지 들어가는 것.

## 2026.11.25 사용 상한 시험

- 단위 시험: 하루 상한 · 대화 하나의 상한 · 리포트 상한(넘쳐도 대화가 끝나지 않음, 짧은 대화는 그대로 끝남) · 1분 횟수 제한 · 보낸 사람 IP 고르기.
- 공용 DB(`UsageLimitDbTest`): 오늘(한국 시간) · 내 것만 세고, 만들지 않은 리포트(NONE)는 빼요.
- 로컬 서버: 로그인 11번째가 429 `RATE_LIMITED`(`Retry-After` 헤더 · JSON), 사람별 121번째 요청이 429, 서버 상태 확인은 세지 않음. 시험 계정은 지웠어요.
- 아직 안 본 것: 배포 서버(Cloudflare 앞단)에서 로그인 횟수가 사람마다 따로 세지는지.

## 2026.11.25 AI 연결 데우기 · 스트리밍 시험 (로컬, 진짜 Claude)

- 서버가 켜지고 AI 연결 데우기가 1.5초 걸렸어요(Models API, 토큰 안 씀).
- 기록이 없는 날로 대화를 만들어(분석 호출 없음) 두 번 말했어요. 첫 말: 첫 글자 1.4초 · 전체 1.9초, 두 번째: 0.6초 · 1.1초(앱 쪽에서 잰 값). 예전에 막 켠 서버의 첫 글자는 3.7초였어요.
- 답변 조각(`token`)이 24~25번, 네트워크 묶음도 25~26번으로 나눠 와서 로컬에서는 스트리밍이 잘 돼요.
- 비용: 대화 두 턴(입력 약 1,350 · 출력 약 170 토큰). 시험 계정은 지웠어요.
- 아직 안 본 것: 배포 서버(Render · Cloudflare)를 거친 스트리밍과 시간.

## 2026.11.25 배포 서버 대화 시간 (폰의 개발 빌드, 진짜 Claude)

| 대화 | 요청 → 첫 글자 | AI 호출 → 첫 글자 | 전체 |
|---|---|---|---|
| 서버가 깬 직후 첫 말 | 5.9초 | 4.7초 | 5.9초 |
| 두 번째 | 1.2초 | 0.7초 | 1.6초 |
| 세 번째 | 1.1초 | 0.5초 | 1.6초 |

- 서버가 켜질 때 AI 연결 데우기는 7.5초 걸렸어요(로컬 1.5초). 무료 서버의 CPU가 0.1개라 처음 쓰는 코드를 불러오는 데 오래 걸리는 것으로 보여요.
- 답이 폰에서 조금씩 나타났어요. Render · Cloudflare를 거쳐도 SSE 스트리밍이 돼요.
- 요청을 받고 AI를 부르기 전까지(대화 확인 · 지난 말 · 오늘 사용량 조회)는 0.5~1.2초예요. 싱가포르 서버와 서울 DB 사이를 여러 번 오가요.
